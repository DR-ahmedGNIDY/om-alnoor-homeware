# Pharma One Cosmetics

منصة تسوق إلكترونية فاخرة للمنتجات التجميلية - أكثر من 7000 منتج من أكثر من 100 براند عالمي.

## 🚀 المميزات

- **تصميم فاخر**: لوحة ألوان سوداء وذهبية بتأثيرات سينمائية
- **RTL عربي**: واجهة مستخدم كاملة باللغة العربية
- **ديناميكية**: فلاتر وبحث وتصنيفات تفاعلية
- **واتساب**: تكامل كامل مع واتساب للطلبات السريعة
- **سلة تسوق**: إدارة سلة ذكية مع Zustand
- **لوحة تحكم**: إدارة كاملة للمنتجات والبراندات والطلبات
- **NextAuth**: تسجيل دخول بالبريد وجوجل
- **MongoDB**: قاعدة بيانات قابلة للتوسع

## 📦 التقنيات

- Next.js 15
- React 19
- TypeScript
- Tailwind CSS
- Framer Motion
- MongoDB + Mongoose
- NextAuth.js v5
- Cloudinary
- Zustand

## 🛠️ التشغيل

```bash
# تثبيت التبعيات
npm install

# إعداد المتغيرات البيئية
cp .env.example .env.local

# تشغيل خادم التطوير
npm run dev
```
